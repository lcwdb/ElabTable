Node.js 为本机开发工具运行环境；Electron 内置的 Node.js 版本由 Electron 决定，两者不要求相同。原生模块要针对 Electron 的 ABI 和目标架构验证。

Vue、Vite、Electron、esbuild 等依赖在对应任务安装时核验 engines 与相互兼容性，随后锁定版本。当前只确认开发环境，尚未证明完整依赖和安装包兼容。

最低支持的 macOS 版本在 Electron 版本选定时，依据其官方支持范围确定并记录；Windows、Intel Mac 暂不列入已验收范围。

## 目录职责

```text
apps/desktop/       桌面程序，包含界面和 Electron 进程代码
apps/server/        NestJS 云端程序，第三阶段建立
packages/contracts/ IPC 与云端接口使用的 DTO、Schema、事件和错误码
docs/               工程说明与验收记录
prototype/          现有设计参考图片
```

workspace 是在一个仓库中管理多个包。目录按开发进度建立，不预先生成空模块。

## 构建职责

- Vite：提供 Vue 开发服务器，并构建 renderer 页面。
- esbuild：编译 Electron main、preload，后续加入 runtime。
- 自写 Node 脚本：等待页面服务就绪、启动 Electron、监听桌面代码变化并清理子进程。
- electron-builder：将生产代码和资源制作成桌面安装包。
- TypeScript / vue-tsc：检查类型；esbuild 编译成功不代表类型检查通过。

桌面入口与 preload 的模块格式、输出扩展名在对应构建任务中明确配置；preload 遵守 Electron sandbox 限制，不直接引入完整 Node.js 能力。

## Git 约定

- 每阶段通过验收后必须 commit；阶段内可以提交完整小任务。
- 提交前查看差异，仅暂存相关文件。
- 密钥、环境实际配置、数据库、附件、日志、依赖目录和构建产物不提交。
- 当前方案文档尚未提交，第一阶段提交时纳入；参考图片需查看确认后再纳入。
- 提交说明描述结果，例如 `chore: 建立工作区与类型检查配置`。
